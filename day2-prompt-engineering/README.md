# Week 5 Day 2 - Prompt Engineering & System Prompts with Ollama

## Objective

Learn prompt engineering and system prompts using a locally running LLM with Ollama.

## Model

- Llama 3.2:3B

## Technologies

- Python
- Ollama
- Requests
- Large Language Models

## Tasks Completed

- Used Ollama for local LLM inference
- Created a custom system prompt
- Built a Python program using the Ollama API
- Tested five cybersecurity prompts
- Generated responses using the custom system prompt

## System Prompt

The model was instructed to act as a cybersecurity tutor, explain concepts in simple English, use practical examples, and avoid harmful attack instructions.

## Test Prompts

1. What is the CIA Triad in cybersecurity?
2. What is a firewall?
3. What is encryption?
4. What is a brute-force attack?
5. What is phishing?

## Output Evidence

The output screenshots show the responses generated by the local LLM for the five cybersecurity prompts.

## Learning Outcome

A system prompt guides the behavior, role, and response style of a language model. Prompt engineering helps produce more useful and consistent responses.
