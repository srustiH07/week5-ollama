# Week 5 Day 5 - Local Q&A Bot with Ollama

## Objective

Build a local Q&A bot using Ollama and locally running Large Language Models.

## Technologies Used

- Python
- Ollama
- Llama 3.2:3B
- Qwen 2.5:3B

## Tasks Completed

### 1. Local LLM Inference

- Verified Ollama installation.
- Used the locally installed `llama3.2:3b` model.
- Tested local question-answering.

### 2. Custom System Prompt

The application uses a custom system prompt that instructs the model to behave as a helpful AI/ML mentor and provide clear and concise answers.

### 3. Five Prompt Tests

The following five prompts were tested:

1. What is artificial intelligence?
2. What is machine learning?
3. What is a firewall?
4. What is encryption?
5. What is a brute-force attack?

### 4. Model Comparison

The same three questions were given to both models:

- Llama 3.2:3B
- Qwen 2.5:3B

The responses were compared for clarity, detail, and usefulness.
